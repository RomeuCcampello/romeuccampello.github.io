# Portfólio de Romeu Campello

Site pessoal com projetos de desenvolvimento de software, IA aplicada e automação.

[Visitar o portfólio](https://romeuccampello.github.io/)

## Conteúdo
- Sistemas de energia desenvolvidos na Galva e demonstração de conferência de faturas.
- Fluxo comercial de propostas e contratos.
- Galeria de interfaces com identificadores e valores ocultados.
- Dashboard Swfast com exemplo de análise de dados.
- Formação, reconhecimento acadêmico, idioma e contato.

## Executar localmente
Com Python instalado, execute `python -m http.server 8000` na raiz e abra `http://localhost:8000`.

O site usa HTML, CSS e JavaScript. O GitHub Pages publica a branch main a partir da raiz.
